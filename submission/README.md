# Bike Sharing Analysis Dashboard

## Description
Dashboard interaktif ini dibuat untuk menganalisis tren penggunaan layanan penyewaan sepeda harian berdasarkan musim, tipe hari (hari kerja vs hari libur), dan kategori suhu udara.
