# 🚲 Bike Sharing Analytics Dashboard

Aplikasi dashboard interaktif berbasis Streamlit untuk menganalisis performa dan pola penyewaan sepeda harian berdasarkan musim, tipe hari, dan kategori suhu udara.

---

## 🚀 Fitur Dashboard
- **Filter Interaktif:** Memilih tahun (2011, 2012, atau Semua Tahun) dan musim (Spring, Summer, Fall, Winter).
- **Ringkasan Metrik:** Menampilkan Total Penyewaan, Rata-rata Penyewaan per Hari, dan Total Hari Terdaftar.
- **Visualisasi Data:** 
  1. Bar chart rata-rata penyewaan sepeda per musim & tipe hari.
  2. Boxplot distribusi penyewaan sepeda berdasarkan kategori suhu udara.
